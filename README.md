# Projet de valorisation d'actifs

Prototype de machine learning développé avec scikit-learn pour estimer la valeur d'un actif à partir de ses caractéristiques.

## Objectif

Construire un projet complet comprenant :

- préparation des données
- modèles de régression
- évaluation des performances
- analyse des erreurs
- explicabilité
- mise à disposition du modèle
